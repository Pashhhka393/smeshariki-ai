Данный проект предназначен для моего учебного заведения к мероприятию. 
Сайт написан на Next.js, TypeScript, Tailwind, Zustand, также lucide-react для иконок и GigaChat API для имитирования поведения персонажей из мультика.
Суть состоит в том, что пользователь выбирает собеседника, каждый собеседник общается с пользователем в своем стиле, своим характером. 
Есть моменты для доработки данного проекта, например, адаптивность под разные разрешения, что будет решено в будущем.
